# 喵咪日事本

在指定频道发 `记笔记 @造化玉猫 内容`（繁简、混写都可以）记一条笔记；用 `/read-diary` 公开查看。

## 用法

| 操作 | 例子 |
|---|---|
| 记笔记 | `记笔记 @造化玉猫 今天在媚笙阁吃了薯饼` / `記筆記 @造化玉猫 今天吃薯餅` |
| 最新五条 | `/read-diary` |
| 某人最新五条 | `/read-diary user:@某人` |
| 关键词（繁简通用、不分大小写） | `/read-diary text:薯饼` |
| 某人 + 关键词 | `/read-diary user:@某人 text:薯餅` |

- 写入：同一个人每 5 分钟一条；正文最多 1000 字；不能 @ 任何人、身份组、频道或 @everyone/@here。
- 查询：同一个人每分钟一次（没查到也算一次）；结果**公开**发在当前频道。
- 原消息删除或编辑都**不会**改变已记下的笔记；V1 不能删除笔记。

## 建议置顶的说明（请管理员发在写入频道）

> 📔 **喵咪日事本**：在本频道发「记笔记 @造化玉猫 内容」就能记一条笔记。
> ⚠️ 笔记是**公开**的：本服任何人都能用 `/read-diary` 查到；删除原消息也**不会**删除笔记。
> 玉猫说"日事本不会被别人看"是玩笑，请不要记密码、住址等隐私内容。

## 管理员配置（`config.json`）

| 字段 | 说明 |
|---|---|
| `guilds.<服务器ID>.enabled` | 关闭后不再监听写入，`/read-diary` 公开提示"还没开放"；已有记录保留 |
| `guilds.<服务器ID>.write_channel_id` | 监听写入的频道 |
| `max_results` / `max_entry_length` / `max_query_length` | 5 / 1000 / 100 |
| `max_entries_per_guild` | 每服上限 10000 条，满了拒绝写入，**不会**自动删除旧笔记 |
| `write_cooldown_seconds` / `read_cooldown_seconds` | 300 / 60 |

## 数据

- 每个服务器一个文件：`data/cat_diary/<服务器ID>.json`（笔记 + 冷却）。`data/` 必须放在持久磁盘上，部署时不要覆盖。
- 写入是"临时文件 + fsync + 原子替换"，不会留下写到一半的文件。
- 文件损坏时该服的读写都会停止并报错，**不会**被当成空文件覆盖；请人工修复或从备份恢复。
- 只支持单个 Bot 进程写入同一个数据目录。
