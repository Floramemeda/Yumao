# 沙滩排球

`/沙滩排球 [目标分]`：开一局（目标分 10–100，默认 12），大家点「加入」，主持人点「开始」。2–10 人，开局随机分成两队（人数差最多 1）。

## 规则

一球分两步：

1. **发球**：发球人点 左边 / 右边（别人看不到）。45 秒不选就随机发。
2. **接球**：对方全队**各自**先点「接左边 / 接右边」，再在只有自己看得到的小面板里选部位（手 / 胸 / 屁股），选了不能改；全部选完立刻结算，60 秒没选的人算发呆。

判定：**方向猜中才碰得到球**，碰到后按部位的成功率判定接没接住。

| 部位 | 成功率 | 接住得分 | 代价 |
|---|---|---|---|
| 手 | 85% | +1 | 无 |
| 胸 | 55% | +3 | 碰到球就弄坏上衣 |
| 屁股 | 55% | +3 | 碰到球就弄坏下衣 |

- 每人一件上衣、一件下衣，耐久 1。猜错方向碰不到球，不会损坏；猜中但没接住也算碰到了。
- 服饰坏了还用那个部位，每碰到一次发情度 25 → 50 → 100（上下共用一条），到 100 失能退场。
- **误伤**：猜错方向或猜中没接住的人，有 25% 概率把球砸到同队另一个还在场的人身上（胸或屁股随机），效果和自己碰到一样：服饰没坏就弄坏，坏了就涨发情度，可能因此失能。发呆的人不会误伤。
- 每个接住的人都给本队加分；全队都没接住，发球方 +1。
- 接住了：球打回去，由接住的人之一发球。没接住：发球方继续，队内轮到下一个人。
- 先到目标分的队获胜；一队全员失能时对方直接获胜；连续 3 球没人操作就中止。

## 配置（`config.json`）

| 字段 | 说明 |
|---|---|
| `default_target_score` | 默认目标分（`/沙滩排球` 的可选范围写在 `cog.py`） |
| `parts` | 各部位的得分、成功率、对应服饰 |
| `miss_score` | 全队没接住时发球方得分 |
| `friendly_fire` | 误伤概率与可能打到的部位 |
| `excitement_steps` | 发情度递进 |
| `serve_timeout_seconds` / `receive_timeout_seconds` | 发球 / 接球时限 |
| `allowed_channel_ids` / `allowed_category_ids` | 限制能开局的频道（含其子区）/ 分类，都为空 = 不限制 |

进行中的局存在 `data/beach_volleyball_state.json`，Bot 重启后继续。
