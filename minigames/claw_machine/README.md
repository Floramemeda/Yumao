# 🧸 万象娃娃机（V1）

南域游乐场的随机娃娃收藏小游戏。门票由另一个门票 Bot 管（扣票、每日 10 次都在那边），玉猫只负责开局、抓取、收藏和赠送。

## 开局协议（门票 Bot → 玉猫）

门票 Bot（造化伞娘）在游戏频道发一条消息，正文或 Embed 描述里带：

```text
<@玩家ID> 使用了一张游乐园门票！
……
-# ||[YUNZHOU_CLAW_START]||
-# ||EVENT_ID=<唯一事件 ID，1～100 位字母数字和 _ . : ->||
```

- 每行的 `-#` 小字前缀、`||` 剧透和反引号会先去掉再解析。
- 玩家：优先取标记后的 `USER_ID=…`，没有就取标记前第一个 `<@玩家ID>`。
- `VERSION=` 可省略，省略时按 1 处理；写了但不是 1 会忽略整条消息。

玉猫只处理同时满足这些条件的消息：
- 发送者在 `trusted_bot_ids` 里
- 频道或子区的父频道在 `channel_ids` 里
- 有标记
- 能确定玩家和 EVENT_ID，且格式正确

满足条件后玉猫按 `EVENT_ID` 开一局，并回复一块游戏面板（只 @ 该玩家）。
- 同一个 `EVENT_ID` 只开一局。重复消息、并发处理、重启回扫都不会重复开。
- 不监听消息编辑。
- 重启后会回扫各游戏频道最近 `catch_up_hours` 小时、最多 `catch_up_limit` 条消息，补开离线期间漏掉的门票。
- 一个人连用多张门票会有多局待玩，每局都有自己的面板。面板找不到了用 `/claw resume` 继续，最早的一局先来。

`trusted_bot_ids` 或 `channel_ids` 为空时不会开任何局。

## 一局怎么玩

1. 面板上有三只候选娃娃，显示名字和两条线索（抓取点、摆放位置）。异常特征此时不显示。
2. 选一只，再选抓法：正面夹取、侧边勾取或托底搬运。
3. 确认抓取。服务端按 `clamp(基础成功率 + 位置修正, 40, 90)` 用 `secrets.SystemRandom` 判定一次。
   - 结果写进存档后才显示。
   - 再点任何按钮都只显示已保存的结果。
4. 抓到了：
   - 娃娃获得编号 `YZ-000001`，揭晓异常特征，检查隐藏彩蛋。
   - 自动收进收藏柜。
   - 结果下方有「查看收藏」「赠送好友」两个按钮。

只有局的主人能点这局的按钮。别人点了只会收到一条私密提示。

## 指令

| 指令 | 说明 |
|---|---|
| `/claw resume` | 继续最早一局没玩完的娃娃机（仅自己可见） |
| `/claw collection` | 收藏柜：分页、按全部 / 彩蛋 / 展示中筛选，可以查看详情、设为展示、赠送（仅自己可见） |
| `/claw showcase [玩家]` | 公开展示某人的展示位（最多 5 只） |
| `/claw stats [玩家]` | 战绩：抓取次数、成功次数、当前持有（亲手抓的 / 别人送的）、独特组合、彩蛋、赠出 / 收到 |

## 赠送

1. 在收藏柜详情或抓取结果上点「赠送」。
2. 选接收人，然后确认。
3. 玉猫在当前频道发一条邀请并 @ 对方。邀请上有三个按钮：收下、婉拒、撤回（赠送人）。

规则：
- 待确认期间娃娃被锁定，不能再送给别人。
- 婉拒、撤回或 `gift_expire_hours`（24 小时）过期后自动解锁，娃娃仍归原主人。
- 收下时持有者一次性转移，并取消展示。
- 原始抓取者、编号、词条和彩蛋永远不变。
- 送出不会扣掉原主人的抓取战绩。

## 改内容只需改 config.json

- `subjects` / `moods` / `toy_types` / `quirks`：词条池，键是稳定 id（s01、m01……）。
  - 新增词条就加一个新键。
  - 改名、删除都不影响已抓到的娃娃，因为娃娃身上存了名称快照。
  - 不要把旧 id 拿来指别的词条。
- `grips` / `positions` / `techniques`：线索和抓法的文案。
- `base_rates` / `position_modifiers` / `rate_min` / `rate_max`：成功率。
- `fail_texts`：失败文案。
- `easter_eggs`：彩蛋规则。
  - `match` 写 2～4 个词条名（subject / mood / toy / quirk），没写的视为通配。
  - 多条同时命中时，指定词条多的优先，同样多再比 `priority`。
  - 启动时会校验，词条名写错 bot 会直接报错。

## 存档

存档位置：`data/claw_machine/<服务器 id>.json`。每个服务器一把锁，改动在事务里完成，然后原子写盘。

| 键 | 内容 |
|---|---|
| `events` | EVENT_ID → 局号（唯一约束） |
| `games` | 局：三只候选（含隐藏的异常特征）、面板位置、唯一一次的抓取结果 |
| `dolls` | 娃娃：四词条 id + 名称快照、彩蛋、原始 / 当前持有者、展示、待处理赠礼锁、转手记录 |
| `gifts` | 赠礼：状态 pending / accepted / declined / cancelled / expired |
| `stats` | 玩家累计：抓取次数、成功次数、独特组合、亲自发现的彩蛋、赠出 / 收到次数 |
