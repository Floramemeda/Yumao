# RP 骰点与场次助手

玉猫只掷骰、记数值、发公告；剧情、判定解释和数值变化都由 DM 决定。

## 骰点

| 用法 | 说明 |
|---|---|
| 在自动骰点频道直接发 `1d100>98` | 整条消息恰好是骰式才触发；子区继承父频道；玉猫公开回复 |
| `/roll expression:1d10>5` | 任何频道都能用；格式错误只有自己看得到 |

- 支持 `NdM`，可加 `> >= < <= = ==` 和判定值，比较的是点数**总和**；如 `1d100>98`、`1D20 >= 15`、`2d6`。
- 限额：1–20 颗骰子、2–1000 面、判定值 0–20000；自动识别遇到超限会静默忽略。
- 同一人在同一频道 2 秒内只能掷一次（`roll_cooldown_seconds`）。
- 机器人、Webhook（包括玉猫皮套）发的消息不会触发自动骰点。

`/roll-config add|remove|list channel`：管理员（管理服务器权限）开关自动骰点频道。

## 探索场次

| 指令 | 谁能用 | 说明 |
|---|---|---|
| `/rp start [progress_max]` | DM 身份组 / 管理频道权限 | 在当前频道或子区开局，调用者成为 DM；公开开局消息并弹出 DM 控制台 |
| `/rp dm` | 本场 DM / 管理员 | 打开私密控制台（面板过期或重启后再用一次即可）；顺便补发失败的公告 |
| `/rp status` | 所有人 | 公开查看队伍状态与进度 |
| `/rp end` | 本场 DM / 管理员 | 二次确认后结束；结束后只读留档，同频道可再开新场 |

**DM 控制台**：加入玩家 → 选择玩家 →「修改理智 / 发情值」（`-15` / `+20` 为增减，`80` 为设为 80，留空不改）、
添加/移除异常、移出本场；进度 ±1 或直接设置；结束探索。

- 每名玩家初始理智 100、发情值 0，范围 0–100：增减超出会夹取，公告显示实际变化；直接设置越界会被拒绝。
- 阈值（理智 0 / 发情值 100）只显示数值，不触发任何自动效果。
- 每次实际变更在场次频道发一条公开公告（同一次提交的多项合并为一条，没变化不发）；公告不会 @ 提醒玩家。
- 公告发送失败不撤销已保存的状态，下次操作或 `/rp dm` 时自动补发。

## 配置（`config.json`）

```json
"guilds": { "<服务器ID>": { "roll_channel_ids": [<固定开启的自动骰点频道>], "dm_role_ids": [<DM 身份组ID>, ...] } }
```

`roll_channel_ids` 里的频道（及其子区）固定开启自动骰点，`/roll-config` 不能关闭；`/roll-config add` 可再额外开启其他频道。
当前：云州仙境的『秘境』极乐百触窟。

没配置 DM 身份组时，拥有「管理频道」权限的人可以开局。其余数值（上限、初始值、默认进度、玩家上限 25）也在 `config.json`。

数据：`data/rp_dice/<服务器ID>.json`（自动骰点频道、所有场次与审计事件），需放在持久磁盘，仅支持单个玉猫进程。
